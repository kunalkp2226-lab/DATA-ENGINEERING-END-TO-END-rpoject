🚀 **End-to-End Data Engineering Project | Azure | Databricks | Synapse**

Excited to share my latest hands-on project where I built a complete **data engineering pipeline using Azure services and Lakehouse architecture**.

🔹 **What I built:**

* Extracted data from Kaggle using HTTP via Azure Data Factory
* Designed **dynamic pipelines** using Lookup + parameterization to ingest multiple datasets
* Stored raw data in **Azure Data Lake (Bronze layer)**

🔹 **Transformation Layer:**

* Connected Azure Databricks with Data Lake using **Service Principal (OAuth)**
* Performed data cleaning and transformations using **PySpark**
* Created structured **Silver layer datasets**

🔹 **Serving Layer:**

* Used Azure Synapse Analytics to build **Gold layer (business-ready data)**
* Accessed data securely using **Managed Identity**
* Created views for optimized querying and analytics

🔹 **Key Concepts Applied:**
✔️ Medallion Architecture (Bronze → Silver → Gold)
✔️ Lakehouse Architecture
✔️ Dynamic Data Pipelines
✔️ Secure Data Access (OAuth & Managed Identity)

📊 This project helped me understand how real-world data pipelines are built, automated, and optimized for analytics.
